# Supabase archive

These SQL files are the schema, grants, and seed data for the retired Supabase project `clxkartudaqingisivlv`, which backed the Itinerary Planner demo until it moved to bundled static data.

They are kept for reference only. Nothing in the app reads them, and the project they were written for no longer exists. The live demo data now lives in `data/demo/`.
